Projetos


Durante sua formação no IFPA campus Parauapebas, algumas palavras serão bem comuns e podem acabar confundindo bastante sua cabeça. Ao longo do texto a seguir, nosso objetivo é compreender as diferenças entre os seguintes termos: Projeto de Ensino, Projeto de Pesquisa, Projeto de Extensão e Projeto Integrador.

Projeto de Ensino

Primeiramente, o Projeto de Ensino. Algum tema específico durante as aulas do seu curso chamou sua atenção e despertou curiosidade para saber mais? Ou, quem sabe, gostaria de aprofundar seu conhecimento na área técnica fora do horário de aula? Então, aqui está ele, o projeto de ensino: é um projeto em conjunto entre aluno e professor, que tem como objetivo, por meio de atividades complementares, aprofundar os conhecimentos obtidos em sala de aula de determinado assunto do curso técnico. Vale ressaltar que tal projeto é feito fora da carga horária normal de aula e o docente é responsável por guiar o projeto. Em resumo, seu principal intuito é complementar a formação dos estudantes e proporcionar desenvolvimento acadêmico a partir da reflexão do conteúdo posto em sala de aula através de práticas extras.

Projeto de Pesquisa

Agora, você concorda que é muito difícil fazer um bolo sem antes preparar a receita que contém o passo a passo, certo? Com uma pesquisa não é diferente. Antes de realizar qualquer pesquisa ou projeto, a coisa mais importante a se fazer é justamente planejar essa pesquisa. O chamado Projeto de Pesquisa tem justamente esse objetivo.

No projeto de pesquisa, nós fazemos a elaboração de metas, seleção de técnicas e métodos a serem utilizados, quais dados serão coletados, como coletar esses dados, o que fazer com esses dados, como garantir que esses dados são confiáveis, qual o prazo da pesquisa, quais os recursos disponíveis, como elaborar a conclusão do projeto e outra infinidade de decisões que precisam ser tomadas antes de se começar. Esse planejamento é extremamente necessário, visto que ele ajuda a garantir que os objetivos da pesquisa foram atingidos, que os dados obtidos são confiáveis, além de ajudar a deixar o projeto mais objetivo e de fácil compreensão, no intuito de passar a informação de forma clara para quem está lendo. Um projeto de pesquisa bem-feito é “meio caminho andado” para que a pesquisa gere informações que realmente contribuam para uma produção de conhecimento significativa.

Projeto de Extensão

No entanto, quando falamos do projeto de extensão, as coisas mudam um pouco. Os outros tipos de projetos comentados até agora têm uma interação do campus para o próprio campus. “Como assim?!” O Projeto de Extensão vai além da sala de aula e do campus em si. Tal projeto tem como finalidade a aplicação dos conhecimentos que você adquiriu em sala de aula para a comunidade externa. O principal elemento abordado aqui é retribuir para a sociedade o conhecimento que você ganhou de forma prática através de serviços e pesquisas, colaborando para o desenvolvimento da sua comunidade. Um ponto importante é que o projeto de extensão traz muitos benefícios aos discentes que as praticam, uma vez que é uma oportunidade de usar a técnica aprendida, desenvolver habilidades e ganhar experiência, contribuindo para uma futura formação profissional.

Projeto Integrador

Em último lugar, esse é o que está presente nos pesadelos dos alunos. Muito provavelmente você já ouviu o termo “TCC”, que significa “Trabalho de Conclusão de Curso”, e é um requisito obrigatório para os que estão fazendo algum curso superior receberem seus diplomas. Mas, não precisa entrar em desespero, você não vai precisar elaborar um (não agora, pelo menos). Para obter seu diploma de conclusão de ensino médio juntamente com seu diploma de técnico, será necessário fazer o que nós chamamos de Projeto Integrador, ou PI, para os mais íntimos.

O Projeto Integrador visa unir os conhecimentos adquiridos durante a sua formação para o planejamento e a produção de um projeto que busca alterar de forma positiva a realidade da sua comunidade. É feito em grupos, e os próprios alunos decidem o que vão fazer, além de escolherem um professor ou vários professores das áreas técnica ou básica para serem seus coordenadores durante a realização. Assim como o TCC para os alunos de faculdade, o PI para os alunos de cursos técnicos é um componente curricular obrigatório. Ou seja: sem PI, sem diploma. Não entenda errado, não é um “bicho de 7 cabeças”, é apenas trabalhoso e demanda tempo e planejamento. Portanto, a melhor dica para a realização desse projeto é: comece o quanto antes! Forme seu grupo, selecione os professores, escolha qual será o projeto, converse com seus veteranos e busque tirar todas as dúvidas com seus orientadores de como fazer o PI do início ao fim. E então, mão na massa!
